# surya758/homebrew-tap

Homebrew formulae.

```sh
brew tap surya758/tap
brew install kuro
```

| Formula | Description |
|---|---|
| [`kuro`](Formula/kuro.rb) | Terminal anime streaming client that plays in IINA — [repo](https://github.com/surya758/kuro) |

`kuro` also needs IINA, which is a cask rather than a formula:

```sh
brew install --cask iina
```
